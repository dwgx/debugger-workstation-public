# mcp-pin-lt2

Vendor Python MCP backends (wireshark, frida, volatility3, reqable, imhex) break on mcp 2.x (FastMCP renamed / Server.list_tools gone). Pin mcp>=1,<2 in those venvs. Wireshark smoke PASS 14 tools after pin. FLOSS stack/tight/decoded timeout 45s on 7z.exe; use scripts/floss-agent.ps1 --only static. r2pm -ci r2mcp has no R2PM_INSTALL_WINDOWS.
