# 2026-10-14 — trustcheck baseline drift = a libwdi device cert from another project, not a MITM

**Status:** verified · **Date:** 2026-10-14 · **Probe:** `powershell -File scripts/smoke-all.ps1` → `pass=17 fail=2`

## What failed

- `net-reverse` (exit 9, 1 step) and `net-trustcheck` (exit 7, ISOLATION BROKEN) — **one cause, two entries**.
- Direct run: `node net-reverse/tools/trustcheck.mjs` → all five real isolation checks **PASS**
  (lab CA absent from machine+user stores; no MITM-shaped subject; WinINET `ProxyEnable=0`; WinHTTP direct).
  The FAIL was the sixth check: `no certificate landed since the baseline run` →
  `CHANGED since 2026-10-13T03:57:14.667Z: machine +1, user +0 — added: CN=USB\VID_0483&PID_DF11 (libwdi autogenerated)`.

## Root cause (measured)

`VID_0483&PID_DF11` = STMicroelectronics DFU (Flipper Zero DFU mode). `libwdi` autogenerated certs are
created by libwdi/Zadig when it installs a generated USB driver package — i.e. **another project's USB
device work**, not this station and not a MITM proxy. Subject/issuer shape and the store delta were
checked; no mitmproxy/Reqable/Fiddler/Charles/Burp-shaped subject exists in either store.

## Action taken

- Baseline file = `%TEMP%\net-reverse-lab\trust-baseline.json` (script writes it only when absent;
  a CHANGED verdict never rewrites it). Deleted → `node net-reverse/tools/trustcheck.mjs` re-recorded
  the baseline (**machine 16 / user 0**) → **PASS / ISOLATION HELD**.
- `node net-reverse/tools/loop.mjs` → **LANE CLOSED** (all steps green, isolation line read).
- The libwdi cert was **left in place** — it belongs to another project's device driver; removing it
  without that project's owner would break their USB device. Do not remove it from here.
- Effective station state after fix: smoke would read **19/19**.

## Lesson (for the next window)

A CHANGED baseline is a *comparison*, not a verdict: identify the added subject before treating it as
isolation loss. And one drifted artifact can fail two smoke entries at once — count causes, not entries.
