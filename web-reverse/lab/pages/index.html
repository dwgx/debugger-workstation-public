web-reverse lab target

Loopback-only. Four surfaces:

  • /plain — readable signer: HMAC-SHA256 over ts + "." + body, key in source.
  • /obf — hardened signer: string array, mangled identifiers, flattened control flow.
  • /fingerprint — bot-detection surface: scores header + client signals, explains itself.
  • POST /api/submit — signature gate: 401 bad/stale, 409 replayed, 200 accepted.

Drive it with tools/capture.mjs (CDP), then tools/recover.mjs and tools/replay.mjs. Method: web-reverse/README.md.
